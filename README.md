# Python Learning Projects

Small Python scripts I wrote while learning Python, from the basics up to simple networking tools.

## Contents

| Folder / file | What's in it |
|---|---|
| `Basics/` | Variables, conditionals, loops, functions, and a small challenge |
| `builtin_functions/` | Practice with Python's built-in functions |
| `classes_and_Objects/` | Classes and objects, plus a word-count project |
| `Networking/` | DNS lookup and reverse DNS lookup using `socket` |
| `If_a_webiste_is_up.py` | Checks whether a website is reachable on port 443 |
| `PortChecker.py` | Checks whether a single port on a host is open |
| `MiniPortScanner.py` | Scans a range of ports on a host |

## Running

All scripts use only the Python standard library (Python 3):

```bash
python3 MiniPortScanner.py
```

> Only scan hosts you own or have permission to test.
